# Windows installation

Use 64-bit Windows 10 or 11 and Python 3.10-3.13. Download Python from python.org and enable **Add Python to PATH** during installation. Double-click `install_windows.bat`; it creates an isolated `.venv`, installs the pinned dependencies, and installs this package in editable mode. Double-click `run_windows.bat` to open the local application. If a corporate proxy blocks package downloads, configure pip for that proxy and rerun the installer. No Anaconda installation or GPU is required.
