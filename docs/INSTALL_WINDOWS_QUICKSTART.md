# ZHU MolEnergy Workbench — Windows Quick Start

1. Use Windows 10/11 x64 and extract the complete installer ZIP to a writable folder. Spaces, Chinese characters and non-ASCII usernames are supported.
2. Double-click `Setup_ZHU_MolEnergy.bat`.
3. Wait for the private Python runtime, offline dependencies, model verification and smoke prediction to finish.
4. Double-click the created desktop shortcut **ZHU MolEnergy Workbench**.
5. Stop with Ctrl+C in the launcher console or `Stop_ZHU_MolEnergy.bat`.

No Anaconda or pre-existing Python is required. Setup does not modify global PATH and does not require a network connection. xTB is optional: obtain a compatible native Windows build separately, then enter its `xtb.exe` path in Molecular Explorer. The core prediction and visualization features work without xTB.
